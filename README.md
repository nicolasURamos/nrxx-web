# NR-XX (versão web)

Jogue no navegador: https://nicolasuramos.github.io/nrxx-web/

O NR-XX é um jogo sério sobre as Normas Regulamentadoras de segurança do trabalho, feito no Trabalho de Conclusão de Curso de Nicolas Uriel Ramos (Engenharia de Computação, UNIPAMPA, Campus Bagé). Um detetive investiga acidentes de trabalho, e cada caso é uma fase de plataforma que ensina uma norma. O primeiro caso trata da NR-35, trabalho em altura.

Precisa de um computador com teclado. Controles: A e D (ou as setas) andam, Espaço pula, Shift dá um impulso, E prende ou solta o talabarte e Esc pausa.

Este repositório guarda só o jogo exportado, atualizado automaticamente a partir do código-fonte. Os créditos de arte, som e fontes estão em `CREDITOS.md`.
